# Módulo 06 - Páginas e componentes (a HomePage completa)

Até aqui já possuímos:

- Roteamento entre telas.
- Estilização com Tailwind.
- Hooks de leitura e escrita conectados à API.
- Formulários validados com react-hook-form + zod.

Neste módulo iremos juntar todas essas peças na tela mais completa do
projeto: a `HomePage`.

Neste módulo iremos aprender:

- Como separar a lógica de uma página (hooks) do seu desenho (componente).
- Como compor uma tela a partir de vários hooks e componentes menores.
- Como tratar os estados de carregando / erro / vazio / com dados.

Arquivos deste módulo:

- hooks-da-pagina.md
- composicao-da-home.md

Todos os exemplos apresentados neste módulo são retirados da página
`HomePage`, a tela principal do projeto.
